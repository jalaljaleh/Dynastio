# 🔐 Privacy Policy

This Privacy Policy explains how Dynast.io Bot (“we,” “us,” or “the Bot”) collects, uses, discloses, and safeguards your information when you install or interact with the Bot on Discord. By inviting Dynast.io Bot to your server, you consent to the practices described here.

---

## 📥 Data We Collect

We collect minimal information needed to power the Bot’s features:

- Discord user IDs
- Server IDs and channel IDs  
- XP earned and level progression  
- Timestamps for messages (content length only, not full message text)  
- Optional game account identifiers (if you choose to link)

---

## ⚙️ How We Use Your Data

Your information is used strictly to provide and improve Bot functionality:

- Calculate and store XP/levels per server  
- Assign and manage roles based on levels  
- Sync optional game ranks when accounts are linked  
- Generate leaderboards and participation stats  
- Send notifications and updates about Bot activity

---

## 🔄 Data Sharing & Disclosure

We do not sell, rent, or trade your personal data. Data sharing is limited to:

- Discord’s API for user and server identification  
- Optional game integration APIs, when you explicitly link your account  
- Authorized developers and trusted contractors for maintenance and support  

---

## 🗄️ Data Retention

We retain your data only as long as it’s necessary to provide Bot services or until you request deletion:

- User data can be deleted upon request via GitHub Issues or direct message  
- Backups older than 30 days are purged automatically

---

## 🔒 Security Measures

We employ industry-standard safeguards to protect your data:

- Encrypted storage for sensitive identifiers  
- Secure HTTPS connections for all API calls  
- Regular audits and updates to address vulnerabilities  

---

## 👤 Your Choices & Rights

You have control over your information and can:

- Request full deletion of your data through GitHub Issues or Discord DM  
- Opt out of non-essential notifications  

---

## 🌐 Third-Party Services

Dynast.io Bot may integrate with:

- Discord’s API for core functionality  
- Dynast.io game servers (optional sync)  

We are not responsible for the privacy practices of these third parties. Please review their policies separately.

---

## 📝 Changes to This Policy

We may update this Privacy Policy to reflect changes in our practices. When we do, we will:

- Post the revised policy in the GitHub repository  
- Announce significant changes via Bot notifications  

Continued use of Dynast.io Bot after updates constitutes acceptance of the new policy.
